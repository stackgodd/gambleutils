# Contributing

Thanks for helping improve this repository.

## Before making changes

- Check existing issues and pull requests to avoid duplicating work.
- Keep each change focused and explain the reason for it.
- Follow the existing Java formatting and naming conventions.
- Do not commit credentials, access tokens, private server details, or other secrets.

## Pull requests

Include a short summary of the change, the files affected, and any checks you ran. If a check could not be run, state that clearly rather than reporting it as passing.

For bug reports, include the relevant error message, steps to reproduce, and the Minecraft, Fabric Loader, Fabric API, and Java versions involved. Remove personal information and secrets from logs before sharing them.
